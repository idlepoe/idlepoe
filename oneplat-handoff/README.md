# 맥북에서 이어서 작성할 서류

개인 맥북 1대만 반입하는 가정입니다. 첨부한 엑셀과 이력카드 초안을 사용하고 원본 양식과 사진은 포함하지 않았습니다.

## 맥북 GPT에 요청할 내용

엑셀의 반입 PC 목록에 이 맥북의 정확한 모델명, 시리얼번호, macOS 버전과 디스크 정보를 확인해서 입력해 주세요. 제조사는 Apple, 구분은 노트북입니다. 테스트용 모바일 단말기는 포함하지 않습니다. 장비정보는 로컬에서 확인하고, 필요한 범위만 작성하세요.

현재 Windows용 디스크 FT/FL 안내 양식이므로 macOS에서 대응되는 정보를 확인하되 은행 요구 형식과 일치하지 않으면 임의로 채우지 말고 미확인으로 남겨 주세요. 원본 안내 PDF는 이번 Git 전달 대상에서 제외했습니다.

직책, 투입등급, 계약형태, 계약금액, 투입일, 종료일, 참여기간, 참여율, 근무층수, LOB, Role, Group은 미정이므로 빈칸을 유지하세요. 소속 DXC는 담당자가 지시한 서류 기재값이며 고용계약 상대방 확정을 의미하지 않습니다.

이력카드는 기존 이력에 근거하여 프로젝트 12건을 입력한 초안입니다. 생산관리 기간을 개발 경력에 합산하지 마세요. 해당분야 총 경력은 기간 중복과 공백을 확인한 후 기재하세요. 캐시카 DB는 Oracle이고 업무는 중고차 관련 서류 발급입니다. 학력은 사용자 확인에 따라 강원대학교 산업공학과 졸업으로 정정했습니다.

서명, 개인정보 동의 체크, 메일 발송, 보안 설정 변경, 소프트웨어 설치, 디스크 포맷은 하지 마세요. 이력카드의 페이지 배치는 최종 검수 전이므로 표 잘림과 페이지 넘김을 확인하세요.

업데이트 결과는 별도 파일로 저장하고, 시리얼번호 등 추가 장비정보는 공개 Git에 자동으로 푸시하지 마세요.
